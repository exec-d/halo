# Architecture

*[Français](../architecture.md)*

## Two halves

An Android widget is a native view displayed by the launcher; Flutter does not
draw on the home screen. Halo therefore has two halves:

| Side | Role | Location |
| --- | --- | --- |
| Flutter + [IUX](https://github.com/systm-d/IUX) | Catalogue, settings, previews, pinning, permissions | `lib/` |
| Kotlin | Data (calendar, weather, system), widget and wallpaper rendering, refreshing | `android/app/src/main/kotlin/dev/levilainpetit/wux/` |

```
lib/
  main.dart                 entry point, licences
  src/app.dart              IUX theme, start screen (catalogue or a widget's settings)
  src/home_widgets/         Dart description of the widgets (catalog.dart)
  src/platform/             WuxPlatform: the only boundary with Android
  src/previews/             previews: PNGs rendered by Android
  src/screens/              catalogue, settings for each widget type, wallpaper, settings, about
android/app/src/main/kotlin/dev/levilainpetit/wux/
  MainActivity.kt           dev.levilainpetit.wux/native channel, permissions
  calendar/                 reading the calendar, splitting into days and lines
  weather/                  Open-Meteo: forecasts, pollen, cache, refreshing
  system/                   battery and its history, device, Bluetooth, screen time, mobile data
  widgets/                  one AppWidgetProvider per widget, ALPHA_8 drawings, previews
  wallpaper/                Circuit animated wallpaper
```

## How the two halves talk

- **Settings**: written by Flutter with `home_widget` under the key
  `<widget id>.<name>` (for example `agenda_one_column.calendars`), read back
  by the Kotlin widget. Each write redraws the widgets.
- **`dev.levilainpetit.wux/native` channel**: everything else (permissions,
  city search, previews, status). Dart screens only talk to the
  `WuxPlatform` interface, which makes it possible to test them with
  `test/fake_platform.dart`.
- **In-app previews**: Android draws the real widget (`WidgetPreviews.kt`,
  each widget implementing `PreviewableWidget`) and sends it as a PNG; nothing
  is redrawn on the Dart side. The catalogue uses sample data
  (`SampleData.kt`, `sample()` in the system sources).
- **Previews in the launcher's list**: `android:previewLayout`, sample layouts
  (`res/layout/preview_*.xml`) with sample images (`tool/sample_assets.py`).

## Widget rendering

- **`RemoteViews`**, not Glance: Glance allows neither shadow nor glow on
  text.
- **No background, no rounded corners** in the widgets; the launcher still
  rounds the corners of the widget area, hence a margin of 12 dp on the sides
  and 8 dp at the top and bottom (`res/values/dimens.xml`).
- **Fonts**: the launcher has no access to the app's fonts; text uses the
  system mono font and the time Roboto extra bold.
- **Colours**: `res/values-v31/colors.xml` points to the system accent colours
  (Material You); `res/values/colors.xml` is the fallback for versions before
  Android 12.
- **Readability**: all text has a dark shadow (`text_shade`) that sets it
  apart from a busy background; lines and icons keep their glow.
- **Drawings**: graphics (weather, battery, dial, data) are white `ALPHA_8`
  bitmaps, tinted by the layout (`android:tint`); shades are done through
  opacity. The fixed glowing icons are PNGs generated by
  `tool/clock_assets.py`.
- **Sizes**: on Android 12+, one layout per size reported by the launcher
  (`RemoteViews(Map<SizeF, RemoteViews>)`), for portrait and landscape.
- **Time that ticks on its own**: `TextClock` (clock, world clock) and
  `Chronometer` (time since boot) run without waking the app.

## Freshness

| Data | Triggers |
| --- | --- |
| Agenda | Calendar change (WorkManager content trigger), end and start of an event today, 6 pm, midnight, setting change, system update (30 min) |
| Weather | WorkManager every hour with network; on each system update, a direct download if the forecast is more than 45 minutes old (WorkManager tasks of an idle app are delayed); when Halo is opened |
| Detailed system | WorkManager every 15 minutes, system update, returning to Halo |
| Earbuds | Bluetooth connection and disconnection |

## Decisions

| Topic | Choice |
| --- | --- |
| Colours | Wallpaper accent (Material You, Android 12+) |
| Distribution | APK signed with a shared debug key, published on GitHub |
| Minimum Android | 8.0 (API 26) |
| Calendar | Read-only (`READ_CALENDAR`) |
| Weather | Open-Meteo: free, no key, no account |
| UI library | IUX, pinned to a commit (not published) |

## Signing

All builds are signed with `android/app/debug.keystore`, shared by the CI and
development machines: a new APK installs over the previous one. This key is
public; it is not suitable for publishing on an app store.
